# Overview

ZXTune project is aimed to play music in variety of formats, chiptunes primarily.
End-user apps may be used by average user, but strongly recommended to know about domain (old computers, music, demoscene heritage)
for effective usage.

## Toolset

* git, GNU make
* C++20, STL, boost, Qt (for `zxtune-qt` only)

## Sources

Source code maintainability is in priority. Write as few new code as possible.
Naming is crucial, code sources are encouraged to be read as a plain english text where possible.
Implement similar functionality via similar ways.
